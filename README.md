# 面向计算机统考 408 学习平台 · 在线演示

408 考研学习平台的纯静态演示版，可直接通过 GitHub Pages 访问。

本项目为本科毕业设计，系统完整实现采用 **Vue 3 + Spring Boot 3 + MySQL + Redis**，
本仓库是打包后的前端演示版：**接口逻辑由同一份业务代码在浏览器内执行，无需任何后端**。

## 主要功能

- **题库**：122 道 408 真题风格题目，题型严格对齐统考卷面（单项选择题 / 综合应用题），支持按科目、章节知识点、题型、难度筛选
- **在线练习**：科目快捷入口、知识点两级联动、难度筛选、实时判分、解析与标准答案
- **模拟考试**：1 套四科综合全真模拟卷 + 4 套单科专项卷，开考计时、交卷自动判分、成绩报告
- **错题本**：自动收录错题，连续答对 2 次自动标记为已掌握
- **算法可视化**：排序、页面置换、进程调度、TCP 三次握手等交互动画，与知识点掌握度联动
- **学习统计**：科目正确率、近 30 天趋势、知识点掌握度雷达、排行榜

## 技术说明

系统采用前后端分离架构：

| 层次 | 技术选型 |
| --- | --- |
| 前端 | Vue 3 + Vue Router + Pinia + Element Plus + ECharts |
| 后端 | Spring Boot 3 + MyBatis-Plus + JWT |
| 数据库 | MySQL 8 + Redis |
| 演示版后端 | 零依赖 Node 单端口 HTTP 服务 |

本仓库的特殊之处在于：把 Node 后端中的业务逻辑（`api-core.mjs`）原样搬到浏览器里执行，
通过 axios 自定义 adapter 接管 `/api` 请求，数据存于浏览器 localStorage。
因此**接口行为与真实后端完全一致，且不需要任何服务器**。

> 数据保存在本机浏览器中，换设备或清除浏览器数据后演示状态会重置。
> 页面右上角「重置演示数据」可一键恢复初始状态。
